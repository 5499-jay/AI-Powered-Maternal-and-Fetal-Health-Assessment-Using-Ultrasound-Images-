# 🧠 Fetal-Net: AI-Powered Maternal & Fetal Health Assessment Using Ultrasound Imaging

## 📌 Project Overview

**Fetal-Net** is an AI-powered healthcare research project designed to support maternal and fetal health assessment through intelligent ultrasound image analysis.

The project explores the integration of **Deep Learning, Computer Vision, Transformer architectures, and Explainable Artificial Intelligence (XAI)** to analyze fetal ultrasound images, study fetal growth patterns, and investigate potential developmental abnormalities.

Fetal-Net focuses on developing an interpretable AI framework that can assist healthcare professionals by providing meaningful insights into fetal development and supporting clinical decision-making.

The project emphasizes **prediction interpretability, medical image analysis, and AI-assisted healthcare research**.

## 🎯 Project Objectives

- Analyze fetal ultrasound images using advanced deep learning techniques.
- Explore automated fetal feature extraction and classification.
- Investigate fetal growth assessment using biometric measurements.
- Identify imaging patterns potentially associated with fetal abnormalities.
- Improve AI prediction transparency using Explainable AI techniques.
- Develop an interactive prototype to demonstrate AI model computations.
- Support healthcare research through data analytics and visualization.

## 🚀 Key Features

### 1. Ultrasound Image Analysis
- Processes fetal ultrasound images for AI-based analysis.
- Explores image preprocessing, feature extraction, and classification.
- Investigates patterns associated with fetal development and potential abnormalities.

### 2. Hybrid CNN–Transformer Architecture
- **Convolutional Neural Network (CNN):** Extracts spatial features and important patterns from ultrasound images.
- **Transformer:** Explores attention mechanisms to capture relationships between image features.
- Combines convolutional feature learning with attention-based analysis.

### 3. Explainable Artificial Intelligence (XAI)
- Explores a **Progressive Concept Bottleneck Model** for interpretable predictions.
- Connects model outputs with clinically relevant intermediate concepts.
- Supports investigation of how learned image features influence predictions.
- Aims to improve transparency and understanding of AI-assisted assessments.

### 4. Fetal Growth & Biometric Assessment
Focuses on important fetal biometric parameters:

- **BPD:** Biparietal Diameter
- **HC:** Head Circumference
- **AC:** Abdominal Circumference
- **FL:** Femur Length

These parameters are commonly used in clinical fetal growth assessment and gestational age estimation.

### 5. Interactive AI Prototype
- Includes a browser-based demonstration of CNN computations.
- Illustrates self-attention mechanisms used in Transformer architectures.
- Provides visual explanations of selected AI processing concepts.
- Helps users understand the working principles of the proposed architecture.

### 6. Healthcare Data Analytics
- Includes a Power BI/Tableau-ready analytics workbook.
- Supports exploratory analysis and visualization of project data.
- Helps present research findings and relevant assessment indicators.

## 🔄 Proposed System Workflow

1. **Ultrasound Image Acquisition:** Collect fetal ultrasound images from suitable research datasets.
2. **Image Preprocessing:** Prepare ultrasound images through resizing, normalization, and image enhancement.
3. **Feature Extraction:** Use CNN-based methods to extract important spatial features.
4. **Attention-Based Analysis:** Explore Transformer mechanisms to model relationships between extracted features.
5. **Explainable AI:** Investigate concept-based explanations to improve prediction interpretability.
6. **Fetal Health Assessment:** Study fetal growth indicators and potential abnormality-related patterns.
7. **Data Visualization:** Present relevant results and research insights through interactive visualizations.
