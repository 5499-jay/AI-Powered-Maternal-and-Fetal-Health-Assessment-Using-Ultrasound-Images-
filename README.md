# AI-Powered-Maternal-and-Fetal-Health-Assessment-Using-Ultrasound-Images-
Developed Fetal-Net, an AI-powered maternal and fetal health assessment system using ultrasound imaging. Integrated CNNs, Transformers, and Explainable AI (XAI) to analyze fetal images, identify abnormalities, and support clinical decision-making through accurate, interpretable predictions.
